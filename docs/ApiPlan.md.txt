# Hospital Management System - REST API Documentation

---

# 1. User Service

## Base URL
```
/api/users
```

## Register User
```
POST /api/users/register
```

### Request Body
```json
{
  "name": "Lakshmi",
  "email": "lakshmi@gmail.com",
  "password": "Password@123",
  "phone": "9876543210",
  "role": "PATIENT"
}
```

### Response
```json
{
  "message": "User Registered Successfully"
}
```

---

## Login
```
POST /api/users/login
```

### Request Body
```json
{
  "email": "lakshmi@gmail.com",
  "password": "Password@123"
}
```

### Response
```json
{
  "token": "JWT_TOKEN"
}
```

---

## Get All Users

```
GET /api/users
```

---

## Get User By ID

```
GET /api/users/{id}
```

---

## Update User

```
PUT /api/users/{id}
```

---

## Delete User

```
DELETE /api/users/{id}
```

---

## Change Password

```
PUT /api/users/change-password
```

---

## Forgot Password

```
POST /api/users/forgot-password
```

---

## Reset Password

```
POST /api/users/reset-password
```

---

### User Entity

```text
id
name
email
password
phone
role
status
createdAt
updatedAt
```
